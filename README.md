# pr-media

Screenshots for pull request descriptions. This branch is an orphan: it shares no
history with `main` and is never merged, so binaries stay out of the app's history.

## Layout

```
pr-<number>/<short-label>.png
```

## Linking from a PR

```markdown
![Staff menu](https://raw.githubusercontent.com/JoshuaJumbles/TotalPhotoBooth/pr-media/pr-15/staff-menu.png)
```

Commit straight to this branch; no PRs needed.
